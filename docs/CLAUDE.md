## 1. 사용자

### 1.1 작업자 (나와 함께 일하는 사람)
- 이 서비스는 **코딩 초보자**가 만드는 서비스다.
- 모든 답변, 설명, 질문 창은 **한국어**로 작성한다. (코드 식별자·명령어는 원문 유지)
- 설명은 쉽게 한다. 전문 용어를 쓸 때는 한 줄로 뜻을 덧붙인다.
- 한 번에 많은 것을 바꾸지 않는다. 작은 단위로 작업하고, 무엇을 왜 바꿨는지 짧게 알려준다.
- **모르거나 애매한 부분은 추측하지 말고 먼저 질문한다.** 질문할 때는 선택지를 함께 제시한다.

### 1.2 서비스 이용자 (PRD 2장)
- 주 대상: 특정 관(광교관 등) 방문을 급히 계획하는 30~40대 일반 관람객 (모바일·PC, 모바일 야외 사용 포함)
- 보조 대상: 스크린리더 사용자, 저시력자
- 핵심 과업: 방문 전 **전시 상태, 휴관일, 오시는 길**을 확인하고 방문을 결정한다.

## 2. 기술 스택 (변경 금지)

프로젝트 초기화 때 정한 기술만 사용한다. **아래 스택을 바꾸거나 새 패키지를 추가해야 할 것 같으면 반드시 먼저 질문한다.**

| 구분 | 사용 기술 |
| --- | --- |
| 프레임워크 | React 19 |
| 빌드 도구 | Vite 8 (`@vitejs/plugin-react`) |
| 언어 | JavaScript (`.jsx`) — TypeScript 사용 안 함 |
| 스타일 | 일반 CSS 파일 — Tailwind, SCSS, CSS-in-JS, CSS Modules 사용 안 함 |
| 린트 | oxlint (`.oxlintrc.json`) |
| 패키지 매니저 | npm |
| 폰트 | Pretendard GOV — 로컬 파일 (`src/fonts/`, `src/styles/fonts.css`에서 등록). CDN 사용 안 함 |

### 명령어
```bash
npm run dev      # 개발 서버
npm run build    # 빌드 확인
npm run lint     # 코드 검사
```

### 폴더 구조
```
src/
├─ assets/icons/     # SVG 아이콘
├─ assets/images/    # 이미지
├─ components/       # 공통 컴포넌트
├─ fonts/            # Pretendard GOV 웹폰트 (woff-subset: Regular·Medium·Bold)
├─ pages/            # 화면 단위 컴포넌트
├─ styles/
│  ├─ fonts.css      # @font-face 등록 (400·500·700)
│  ├─ tokens.css     # 디자인 토큰 (Figma 변수·스타일)
│  ├─ reset.css      # 브라우저 초기화
│  ├─ global.css     # 전역 스타일·레이아웃·유틸
│  └─ typography.css # 텍스트 스타일 클래스
├─ App.jsx
├─ index.css         # 스타일 진입점 (styles/* import)
└─ main.jsx
```

## 3. 디자인 규칙

### 3.1 디자인 출처
- 디자인은 **Figma MCP**를 통해 구현한다.
  - Figma 파일: `수원시립미술관 개선` (fileKey `JC6lArQ52rQq8jam3MBChZ`)
  - 완성 시안: `3-4. 완성` 페이지 — 모바일 섹션(`292:6964`), 데스크탑 섹션(`587:12948`)
  - 디자인 시스템: `3-2. 디자인 시스템`, 컴포넌트: `3-3. 컴포넌트`
  - 개발 전달 문서: `핸드오프 문서` 페이지
- 반응형 상세 디자인은 구현 단계에서 **사이즈별 Figma 링크**로 전달받는다. 링크가 없으면 질문한다.
- **PRD와 Figma 시안이 다를 경우 Figma 시안을 우선한다.**
- 색상·글자 크기·간격은 임의로 정하지 않고 `src/styles/tokens.css`의 토큰을 사용한다. 토큰에 없는 값이 필요하면 질문한다.
- `tokens.css`의 값은 Figma 원본값이므로 직접 바꾸지 않는다. "코드 전용"으로 표시된 토큰은 Figma 변수에 없어 코드에서 추가한 것이다.

### 3.2 반응형 (PRD 6장)
| 구분 | 범위 | 기준 디자인 |
| --- | --- | --- |
| 모바일 | ~767px | Figma 모바일 시안 |
| 데스크탑 | 768px~ | Figma 데스크탑 시안 (1440px 기준) |

- **모바일 우선**: 기본 스타일은 모바일 기준, 데스크탑은 `@media (min-width: 768px)`로 덮어쓴다.
- `max-width` 미디어쿼리는 사용하지 않는다.
- 1440px 초과 화면은 콘텐츠를 최대 너비로 제한하고 가운데 정렬, 배경은 화면 전체로 확장한다.
- 최소 지원 너비 360px, 더 좁아도 가로 스크롤이 생기지 않아야 한다.
- 모바일 네비게이션 형태(햄버거 메뉴 등)는 Figma 시안을 따른다.

### 3.3 단위 규칙
- 레이아웃 너비·간격은 `%`와 `rem`을 사용한다. 루트 폰트 크기는 브라우저 기본값(1rem = 16px)을 유지한다.
- 고정 px 너비는 지양하고, `em`은 사용하지 않는다.
- px는 다음 경우에만 허용: border·구분선, box-shadow, 미디어쿼리 브레이크포인트 값, 콘텐츠 영역 max-width
- 화면 높이가 필요하면 `vh` 대신 `dvh`를 사용한다.

### 3.4 공통 처리
- 이미지·영상은 `max-width: 100%`로 부모를 넘지 않게 하고 원본 비율을 유지한다.
- 터치 영역은 최소 `2.75rem × 2.75rem`(44px)을 확보한다.
- hover 효과는 `@media (hover: hover)` 안에서만 적용한다.

### 3.5 접근성 (KWCAG 2.2 · KRDS, PRD 5장) — 최우선 (P1)
- 이미지 속 글자는 반드시 **HTML 텍스트**로 표기하고, 이미지에는 `alt` 대체 텍스트를 제공한다.
- 텍스트 명도 대비 **4.5:1 이상**을 확보한다.
- 상태는 색에만 의존하지 않고 **텍스트를 반드시 병기**한다.
- 캐러셀에는 **정지/재생 버튼**을 제공한다.
- 검색창은 `<label>`을 연결하고, 아이콘 버튼에는 대체 텍스트(`aria-label` 등)를 제공한다.
- 링크 텍스트는 목적지가 드러나게 쓴다. ("자세히 보기", "전시 상세 보기", "오시는 길 & 관람시간")
- 키보드 포커스가 눈에 보여야 한다.

### 3.6 공공언어 표기 (PRD 5.2)
- 전시 상태: **전시 중 / 종료 임박 / 전시 예정** (종료 임박은 "종료 임박 D-3" 형식)
- 프로그램 상태: **접수 중 / 마감**
- 관 명칭: **행궁본관, 광교관, 만석전시관, 북수원전시관**
- 위 표기와 Figma 시안의 문구가 다르면 질문한다.

## 5. 안전 규칙

- **기술 스택 변경 금지.** 새 패키지 설치(`npm install ...`)가 필요하면 이유를 설명하고 먼저 허락을 받는다.
- **파일 삭제·덮어쓰기 전에 확인한다.** 특히 `docs/` 안의 문서(`PRD.md`, `CLAUDE.md`)는 요청 없이 수정하지 않는다.
- **추측해서 만들지 않는다.** 시안·PRD에 없는 내용(문구, 색상, 데이터, 동작)은 질문한다.
- 실제 개인정보, API 키, 비밀번호 등 민감 정보를 코드에 넣지 않는다.
- 작업 후에는 `npm run build`와 `npm run lint`로 오류가 없는지 확인하고 결과를 알려준다. 실패하면 숨기지 않고 그대로 알린다.
- git 커밋·푸시, 배포 등 되돌리기 어려운 작업은 요청이 있을 때만 한다.
- `node_modules/`, `dist/`는 직접 수정하지 않는다.
- Figma 파일을 수정하는 작업(`use_figma`)은 요청이 있을 때만 하고, 읽기 작업과 구분해서 알려준다.
