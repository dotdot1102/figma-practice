## 2. 프로젝트 정보

- **제작 기간**: 2026.09.30 ~ 2026.10.15 (15일)
- **담당 역할**: 개인 프로젝트 (기여도 100%)
- **담당 범위**: Figma 개선 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용 기술

- **React, Vite**: 전시 카드, 상태 배지, 필터 같은 UI를 컴포넌트로 나눠 재사용하고, 빠른 개발 서버로 PC·모바일 화면을 바로바로 확인하며 다듬기 위해 사용
- **GitHub Pages**: 무료 배포
- **Figma**: 개선 디자인
- **Claude**: 바이브코딩 (화면 구현)

## 4. 주요 기능

- [기능 1: 관별 전시 필터와 정렬]
- [기능 2: 텍스트 상태 배지: "전시 중 / 종료 임박 / 전시 예정"을 표시해 전시 상태를 한눈에 확인]
- [기능 3: 방문 정보 바로 확인: 선택한 전시 페이지에서 운영시간, 오시는 길, 예약방문을 페이지 이동 없이 확인]

## 5. 트러블슈팅

### 이슈 1: 모바일에서 스크롤하면 관 선택 필터를 다시 찾기 어려움

- **문제**: 모바일에서 전시 목록을 아래로 내린 뒤 다른 관을 보려면 맨 위까지 다시 올라가야 했음
- **원인**: 관 선택 필터가 목록 상단에만 있어서 스크롤하면 화면 밖으로 사라짐
- **해결**: 필터를 화면 상단에 스티키(Sticky)로 고정해 스크롤 위치와 상관없이 언제든 관을 바꿀 수 있게 수정함

## 6. AI 활용 방식

- **맡긴 일**: '오시는 길 & 지도' 팝업 안에 관별 주소를 넣고, 모바일에서 지도 앱으로 연결되도록 구현
- **핵심 프롬프트**: "오시는 길 팝업에 선택한 관(행궁본관·광교관·만석전시관·북수원전시관)의 주소를 주고, 지도 앱으로 바로 열리게 해줘."

## 7. 회고

- **배운 점**: 국립현대미술관을 벤치마킹하면서, 공공기관 사이트에는 이미 따를 수 있는 표준이 있고 그걸 잘 활용하는 것도 디자인 역량이라는 걸 알게 됐고, "전시 중 / 종료 임박 / 마감"처럼 공공언어를 하나로 통일하는 것만으로도 사용자가 헷갈리는 일이 크게 줄었다.
- **아쉬운 점**: 임시 휴관이나 특별 휴관처럼 예외 상황을 어떻게 안내할지 정하지 못했다. 다음에는 휴관 정보를 정기 휴관과 임시·특별 휴관으로 나눠 관리하고, 해당 관의 전시 카드와 오시는 길 팝업에 "임시 휴관" 같은 텍스트 배지를 자동으로 띄워 방문 전에 바로 알 수 있게 하겠다.
